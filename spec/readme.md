# README

`README.md` at the repository root: what someone finds when they arrive knowing
nothing.

## Authority

It derives from the specs and decides nothing. Where it describes behaviour,
the specs own that behaviour.

## What it must cover

How it is organised is its own business; this is the content, not a structure.

- What Autofile is, in a sentence or two.
- What a *vault* looks like. A small example carries this better than prose.
- Getting started: setting up a *vault* with your agent.
- How to use the CLI.

## How it is written

Short, and written for someone who has never heard of Autofile and may not read
past the first paragraph. It gets them to a working *vault* and stops there:
the *skill* tells agents how to file, and the specs say what is true.
