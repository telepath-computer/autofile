# Autofile

Conventions and a CLI for agents to file information reliably, so it can be
retrieved effectively and used in user-facing surfaces.

`spec/` is authority. Start at [spec/index.md](spec/index.md).

Before writing anything into `spec/`, read [spec/policy.md](spec/policy.md).
In particular, specs are a slop-free zone: a human reads and owns every line.
Propose in conversation and write only what has been agreed.

`docs/` explains and proposes. It never binds.
